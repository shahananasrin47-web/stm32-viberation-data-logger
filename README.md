# stm32-viberation-data-logger

Overview

This academic project involved designing an STM32-based vibration data logger for collecting accelerometer measurements at 15-second intervals and storing measurement records for a planned 12-hour logging period.

System Components

* STM32F401RE microcontroller
* MPU6050 3-axis accelerometer
* AT24C256 EEPROM
* LCD1602 display with PCF8574 I²C interface
* Push-button user controls

Technologies Referenced

STM32, STM32CubeMX, I²C, MPU6050, EEPROM, KiCad
